## 🖨️ تعليمات الطباعة (لمحل الطباعة / Imprimeur)

- **المقاس:** 100 × 200 cm (Portrait)
- **الدقة:** 150 DPI — كافية تمامًا لـ Roll Up يُشاهد عن بعد 1–2 متر
- **الصيغة المفضلة:** ملف الـ JPG أو PDF كما هو، بدون تعديل المقاس
- **ملاحظة:** أسفل 10 سم من التصميم (شريط كحلي غامق) مصمم ليختفي داخل قاعدة الـ Roll Up — لا تضعوا أي نص هناك (وهو فارغ أصلًا)
- الألوان: كحلي + أزرق + أبيض مع لمسة برتقالية (مناسبة لطابعات Bâche/Kakemono)

## 🎨 محتوى التصميم

- **الرأس:** FBM AUTOMATISME + شريط: تركيب • صيانة • تصنيع | INSTALLATION • MAINTENANCE
- **الخدمات (5):** Vérin / Coulissant / Barrière / Rideaux Métalliques / Fabrication Lames — كل واحدة بالفرنسية + العربية
- **الأسفل:** جودة • احترافية • ضمان | QUALITÉ • PROFESSIONNALISME • GARANTIE
- **الخلفية:** صورة حقيقية (بوابة منزلقة + حاجز + ستارة معدنية) محسّنة بالذكاء الاصطناعي ×4
