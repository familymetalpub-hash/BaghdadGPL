# Roll Up — FBM Automatisme 🇩🇿

تصميم Roll Up احترافي للمعرض — مقاس **100 سم عرض × 200 سم ارتفاع**.

## 📁 ملفات الطباعة (جاهزة للمطبعة)

| الملف | الوصف |
|---|---|
| `output/FBM-RollUp-100x200cm-150dpi.jpg` | ملف الطباعة الأساسي — ‏5906 × 11811 بكسل، 150 DPI، جودة 95% |
| `output/FBM-RollUp-100x200cm-150dpi.pdf` | نفس التصميم بصيغة PDF بمقاس حقيقي 1000×2000 مم |
| `output/FBM-RollUp-preview.jpg` | معاينة صغيرة للهاتف/المراسلة |

## 🖨️ تعليمات الطباعة (لمحل الطباعة / Imprimeur)

- **المقاس:** 100 × 200 cm (Portrait)
- **الدقة:** 150 DPI — كافية تمامًا لـ Roll Up يُشاهد عن بعد 1–2 متر
- **الصيغة المفضلة:** ملف الـ JPG أو PDF كما هو، بدون تعديل المقاس
- **ملاحظة:** أسفل 10 سم من التصميم (شريط كحلي غامق) مصمم ليختفي داخل قاعدة الـ Roll Up — لا تضعوا أي نص هناك (وهو فارغ أصلًا)
- الألوان: كحلي + أزرق + أبيض مع لمسة برتقالية (مناسبة لطابعات Bâche/Kakemono)

## 🎨 محتوى التصميم

- **الرأس:** FBM AUTOMATISME + شريط: تركيب • صيانة • تصنيع | INSTALLATION • MAINTENANCE
- **الخدمات (5):** Vérin / Coulissant / Barrière / Rideaux Métalliques / Fabrication Lames — كل واحدة بالفرنسية + العربية
- **الأسفل:** جودة • احترافية • ضمان | QUALITÉ • PROFESSIONNALISME • GARANTIE
- **الخلفية:** صورة حقيقية (بوابة منزلقة + حاجز + ستارة معدنية) محسّنة بالذكاء الاصطناعي ×4

## 🔧 إعادة توليد التصميم

```bash
pip install pillow arabic-reshaper python-bidi numpy fonttools
python3 make_rollup.py
```

- الخطوط (رخصة مفتوحة OFL): **Anton** للعناوين اللاتينية، **IBM Plex Sans Arabic** للنصوص العربية — موجودة في `fonts/`
- الصور الخام في `assets/` (بما فيها نسخة محسّنة `bg-light-x4.png`)
- السكربت `make_rollup.py` يولّد ملفات الطباعة من جديد — عدّل النصوص فيه ثم أعد التشغيل
